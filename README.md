# sing-box-academic 🎓

> 基于 **sing-box** 的现代化 VLESS + REALITY 一键部署与管理脚本。
> 采用 **全球高校独立源站动态优选引擎**，彻底打破 233boy 脚本的中心化大厂特征，100% 杜绝借道 CDN 白嫖中转流量。

---

## 🌟 核心特色与技术优势

| 对比项 | 传统一键脚本 (如 233boy) | sing-box-academic (本项目) |
| :--- | :--- | :--- |
| **伪装域名 (SNI)** | 源码写死 6 个固定大厂域名 (含高危 Cloudflare) | **高校检索优先 / 大厂平滑降级** (已彻底清退 Cloudflare) |
| **流量被偷/白嫖中转** | **极高风险** (默认使用 Cloudflare 等公用多租户 CDN) | **0 风险** (三道防线 + 伪造 SNI 探针过滤) |
| **物理握手 RTT 特征** | 经常跨洋连接欧美服务器，RTT 易被识别 | **VPS 同国/同城独立教育网机房**，握手耗时仅个位数毫秒 |
| **多级容灾与自由度** | 固定单一模式，无备选切换 | **高校优选 / 安全大厂随机 / 自定义输入** 3 种模式任意切换 |
| **稳定性与鲁棒性** | 盲目相信域名可用，未对 301 跳转做处理 | 自动测试裸域与 `www.`，**强校验 HTTP/2 200** |
| **依赖与可用性** | 易因公共第三方 API 宕机导致失效 | **GitHub Raw / CDN 本地高速缓存**，秒级解析 |

## 🚀 一键安装命令

在你的 Linux VPS (Debian / Ubuntu / CentOS / AlmaLinux / Alpine) 执行以下命令：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/<你的GitHub用户名>/<你的仓库名>/main/install.sh)
```

> **提示**：安装完成后，随时可以在终端直接输入 `sb` 唤出交互式管理菜单。

---

## 🛠 命令行快捷参数 (Subcommands)

安装后支持直接使用 `sb` 快捷指令：

```bash
sb               # 打开交互式菜单
sb info          # 查看当前节点配置、VLESS 连接串与终端二维码
sb sni           # 重新执行一次高校优选引擎，换一个新大学 SNI
sb start         # 启动 sing-box 服务
sb stop          # 停止 sing-box 服务
sb restart       # 重启 sing-box 服务
sb status        # 查看运行状态
sb log           # 查看实时运行日志 (tail -f)
```

## 🎯 节点建立与伪装域名匹配流程

```text
               ┌───────────────────────────────┐
               │         1. 建立节点           │
               └──────────────┬────────────────┘
                              ▼
               ┌───────────────────────────────┐
               │       模式选择 / 默认模式     │
               └──────┬────────────────┬───────┘
                      │                │
            [模式1: 高校检索优先]      [模式2: 大厂安全随机]
                      │                │
                      ▼                │
               ┌──────────────┐        │
               │ 本地高校体检 │        │
               └───┬──────┬───┘        │
                   │      │            │
            (全部失败)   (通过)         │
                   │      │            │
                   ▼      │            ▼
         ┌───────────────────┐    ┌───────────────────────────────────┐
         │ 平滑降级至大厂池  │    │ 纯净大厂域名池 (彻底清退Cloudflare)│
         └─────────┬─────────┘    └─────────────────┬─────────────────┘
                   │                                │
                   └──────────────┬─────────────────┘
                                  ▼
               ┌───────────────────────────────┐
               │    3. 写入配置并完成节点建立   │
               └───────────────────────────────┘
```

本脚本内置 **三重安全过滤网**：
1. **HTTP 响应头检测**：自动筛除 `Server: cloudflare`、`cf-ray`、`x-amz-cf-id` (CloudFront)、`Fastly`、`Akamai` 等公共多租户 CDN。
2. **IP / ASN 反查**：解析真实物理 IP 并查验 ASN，彻底排除隐藏在背后的云服务接入点。
3. **主动伪造 SNI 探针**：向目标服务器发送伪造域名握手包，**只有当目标服务器严格拒绝非法握手（确认为独立私有源站）时才准许收录**。
